# MM Beats Limited — SOC Home Lab
This repository documents my hands-on SOC home lab, built to practise the day-to-day work of a Level 1 SOC Analyst.
The lab focuses on monitoring security events, investigating alerts, analysing Windows logs, identifying suspicious activity, documenting incidents, and making escalation decisions.

## Lab Environment
- HR-PC01 — Windows 11 monitored endpoint
- BLACKWOLF — Kali Linux attacker machine
- Wazuh — SIEM monitoring and alert investigation
- Sysmon — Windows endpoint telemetry
- Windows Security Event Logs — Authentication and security events

## Lab Development
This SOC home lab is still being developed. The current work focuses on Wazuh, Windows security logs, alert investigation and incident documentation.
More attack scenarios will be added as the lab develops. I also plan to expand the lab to include Microsoft Sentinel, Splunk and other security tools used in SOC environments.
I will continue building my practical SOC skills alongside relevant cybersecurity certifications, with new investigations and projects added to this repository as I progress.
